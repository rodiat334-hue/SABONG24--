# 🐓 SABONG24-បក្សីកីឡា Telegram Bot

Telegram bot សម្រាប់បក្សីកីឡា — កាលវិភាគ ការផ្សាយផ្ទាល់ លទ្ធផល និងតំណភ្ជាប់។

## Features
- 📅 កាលវិភាគប្រកួតប្រចាំថ្ងៃ
- 🏆 ព័ត៌មានផ្សាយផ្ទាល់
- 📊 លទ្ធផលភ្លាមៗ
- 🎥 តំណភ្ជាប់ផ្សាយ
- 🕐 ម៉ោងធ្វើការ (៨ ព្រឹក – ១១ យប់)

## Deploy on Railway
1. Push to GitHub
2. railway.app → New Project → Deploy from GitHub
3. Add BOT_TOKEN and ADMIN_ID
4. Deploy 🚀
